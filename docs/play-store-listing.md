# Play Store listing — Contacts (`com.callerid.numberlookup.home`)

Copy-paste blocks for Play Console. Every feature named below was checked against
the code, not assumed; see **What this listing deliberately does not say** at the
end for the claims that were left out on purpose and why.

Character budgets: title 30, short description 80, full description 4000.

---

## App title (30 max)

**Recommended**

```
Contacts: Caller ID & Block
```
27 characters. Leads with the install-driving noun (`Contacts`), then the two
highest-volume intents (`Caller ID`, `Block`). Play indexes the title heavily, so
these three carry the most weight of anything in the listing.

**Alternates**

| Title | Chars | Leans toward |
|---|---|---|
| `Caller ID: Contacts & Spam` | 26 | caller-ID intent first |
| `Contacts, Caller ID & Dialer` | 28 | adds the dialer keyword |
| `Phone: Caller ID & Contacts` | 27 | competes for `phone` / dialer traffic |

Do not put a competitor's brand in the title or anywhere else in the listing —
Play treats that as impersonation and it is a common cause of takedowns.

## Short description (80 max)

**Recommended**

```
See who is calling, block spam, look up numbers and keep contacts in order.
```
75 characters. This is the line users actually read in search results, so it is
written as a sentence rather than a keyword list — but it still carries
`calling`, `block spam`, `look up numbers` and `contacts`.

**Alternates**

```
Caller ID, spam blocker, number lookup and a tidy contacts book in one app.
```
```
Know who is calling before you answer. Block spam and search any number.
```

## Keyword coverage

Play indexes the title, the short description and the full description. These are
the terms this listing already carries, in rough order of search volume:

`caller id` · `contacts` · `spam blocker` · `block number` · `dialer` ·
`phone number lookup` · `who called me` · `call blocker` · `unknown number` ·
`call log` · `contacts app` · `spam call blocker` · `scam` · `telemarketer` ·
`missed call` · `number search` · `call history`

Deliberately **not** stuffed: each term appears in a sentence that a human would
actually write. Play's metadata policy treats repeated, irrelevant or
out-of-context keywords as spam, and it is enforced.

## What this listing deliberately does not say

These were all considered and dropped. Each one is a real rejection risk.

| Left out | Why |
|---|---|
| Any competitor's name | Play treats a rival brand in metadata as impersonation |
| "Call recording" | The app does not record calls. `RECORD_AUDIO` is used only by voice search and the sound-level meter, and the listing says so explicitly |
| "Identify any caller" / "find anyone's name and address" | Overstates what the data can do and edges into people-search territory, which Play restricts |
| "100% accurate" / "blocks all spam" | Unverifiable absolute claims |
| "Unlimited access to caller information" | Reads as unrestricted access to personal data |
| Screenshots of real people's numbers | Use placeholder numbers in all store imagery |

Three things the listing does say on purpose, because reviewers look for them:
the microphone disclaimer, the honest limit on identification coverage, and the
in-app route to data deletion.
