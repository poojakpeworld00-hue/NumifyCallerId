What actually changes

Structure 1

List-first

The biggest structural claim: quick-action tiles are redundant. Blocklist and Dialer already exist in the bottom nav, and Lookup is the search bar directly above them. Removing the row and moving Dialer to a FAB frees ~74dp.

  • Search, protection and filter chips pin — they never scroll away
  • Filter chips replace the separate See all destination: Spam and Missed become one tap
  • Ad becomes an inline list item at position 4 instead of a full-width interruption

Cost: the pinned zone is ~150dp, so the visible list is short on small screens. And Tools loses its entry point — it would need to move into Settings.

Structure 2

Collapsing

Keeps every block in today's order. The only change is that the header and protection card scroll away while the search bar pins below them — a CollapsingToolbarLayout with pin on the search.

  • Smallest diff of the three; nothing is removed or reordered
  • First screen looks familiar, but scrolling recovers ~90dp permanently
  • Search stays reachable at any scroll position — currently it scrolls with the content

Cost: the least dramatic. If the current layout feels wrong at rest, this doesn't fix that — it only fixes what happens after you scroll.

Structure 3

Two zones

Groups by intent rather than by component. Search and quick actions are both "do something now"; protection and recent activity are both "look at what happened". Two labelled zones make that split explicit.

  • Protection moves below the ad, next to the activity it summarises — it's a report, not an action
  • The ad lands on a genuine content boundary, so it stops feeling like an interruption
  • Zone labels give the screen a spine without adding chrome

Cost: nothing pins, so search scrolls away like today. Zone headers add ~34dp of pure label.

Styling is untouched in all three — same shape_home_search pill, same shape_home_protection gradient, same tiles, same tokens. If one of these is close but not right, the pieces are swappable: S1's pinned search works with S3's zones, S2's collapsing behaviour works with any of them.
