FEATURE PLACEMENTWhat each page points to in the app
01 · Number Lookup
Primary: Dialer tab → type number → Lookup tile → LookupActivity → Number Details (Country, Carrier, Line type, City, Spam type, Also known as)
Also: Recents row → Identify chip (onIdentify → showLookup)
Also: Call Details → Identify this number
Hero shows: dialer crop with typed number, Lookup tile spotlighted, Number Details card sliding out.
02 · Block Numbers
Primary: Recents row → Call Details → Block (buttonBlock · toggleBlock())
Also: Number Details (after a lookup) → Block action
Manage: Recents header ⚙ Settings → Blocklist (BlocklistActivity) · + to add a number or pattern
Hero shows: Call Details crop with spam verdict, Block tile spotlighted, Blocklist card and "Number blocked" toast.
03 · Contact Management
Primary: Contacts tab (ContactListFragment)
Inside: Search (ContactSearchActivity) · Add contact · Account picker "All contacts" (ContactAccountSheet) · All / Favorites / Recents / Groups chips · A–Z index
Hero shows: Contacts crop with Add spotlighted, favorites strip, A–Z list and Groups card.
