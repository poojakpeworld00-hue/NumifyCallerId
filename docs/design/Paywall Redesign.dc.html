Per-week prices round down to the cent and savings round down to a whole percent, so the screen never overstates a discount. Weekly is the baseline because it's the plan being compared against. Google Play policy requires the full billed amount to be shown more prominently than any breakdown near the purchase button. The CTA's fine print carries it ("then $149.99/year"), and each row's second line repeats it.

PremiumActivity.kt · per-week from Play offer 
private fun weeksIn(period: String) = when (period) {
    "P1W" -> 1.0
    "P1M" -> 52.0 / 12.0
    "P1Y" -> 52.0
    else  -> 1.0
}
private fun perWeekMicros(o: PlanOffer) =
    (o.priceAmountMicros / weeksIn(o.billingPeriod)).toLong()

val weekly = offers.first { it.billingPeriod == "P1W" }
fun savePct(o: PlanOffer) =
    floor((1 - perWeekMicros(o).toDouble() / weekly.priceAmountMicros) * 100).toInt()

fun money(micros: Long, code: String) =
    NumberFormat.getCurrencyInstance().apply {
        currency = Currency.getInstance(code)
        roundingMode = RoundingMode.DOWN
    }.format(micros / 1_000_000.0)
