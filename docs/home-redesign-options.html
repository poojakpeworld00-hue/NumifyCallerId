Trade-offs

Direction A

Quiet

Drops the gradient entirely. A large "Who's calling?" headline plus an oversized search field makes the screen's primary job unmistakable — this is a lookup app first.

  • Protection collapses to a one-line status with a green dot — honest about how little it changes
  • Quick actions become plain outlined circles, no colour coding
  • Ad sits inside the recent list rather than above it, so the list starts higher

Cost: least "premium" looking of the three, and the headline eats ~70dp that a returning user gets no value from.

Direction B

Shield

A dark console card using the existing surface_dark token with a radial gauge. Positions Numify as a protection product, not a phonebook.

  • Gauge gives a single glanceable number that changes daily
  • Quick actions become a horizontally-scrolling chip row — leaves room for a 5th and 6th action later
  • The card stays dark in light mode, matching the Call Details duration card already in the app

Cost: the gauge needs real weekly data; with 0 blocked calls on day one it looks broken. Needs an explicit empty state.

Direction C

Bento

Mixed-size tiles. The tall gradient tile carries the block count, and each quick action becomes a labelled destination with a subtitle instead of a bare icon.

  • Subtitles ("34 numbers blocked", "Trace any number") tell first-time users what each action does
  • Tap targets are far larger than the current 46dp tiles
  • Grid is easy to extend — new features drop in as another tile

Cost: tallest of the three. Recent activity starts near the fold, so the list feels secondary.

All three keep every existing ID and behaviour: the +91 selector, rowPermHint, the call-log permission empty state, See all, the native ad slot, bottom nav and AdMob banner. Only the layout and token usage change.
